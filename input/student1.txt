Q1. Python is a programming language that is widely used for developing software, web applications, automation scripts, artificial intelligence, machine learning, data analysis and scientific computing. It was created by Guido van Rossum and first released in 1991. Python is an interpreted high-level language known for its simple syntax and readability. It supports procedural, object-oriented and functional programming paradigms. The language provides a large standard library and popular frameworks such as Django, Flask, NumPy, Pandas, TensorFlow and PyTorch. Features like inheritance, polymorphism, abstraction and encapsulation help developers build reusable software. Python programs can run on Windows, Linux and macOS. Q2. Data Structures and Algorithms (DSA) deals with efficient organization and processing of data. Common data structures include Arrays, Linked Lists, Stacks, Queues, Trees, Graphs, Heaps and Hash Tables. Algorithms are step-by-step procedures used to solve computational problems. Searching techniques include Linear Search and Binary Search while sorting algorithms include Bubble Sort, Merge Sort, Quick Sort, Heap Sort and Insertion Sort. Time complexity is measured using Big O notation such as O(1), O(log n), O(n), O(n log n) and O(n²). Concepts like Recursion, Dynamic Programming, Divide and Conquer, Greedy Algorithms, BFS and DFS are widely used in competitive programming and technical interviews. Students should compare time complexity before selecting an algorithm because an efficient solution reduces execution time and memory consumption. Q3. Processor Architecture describes the internal structure of a CPU and the way instructions are executed. A processor contains an Arithmetic Logic Unit (ALU), Control Unit (CU), Registers, Cache Memory and Buses. The instruction cycle consists of Fetch, Decode, Execute, Memory Access and Write Back stages. Modern processors improve performance using pipelining, superscalar execution, branch prediction and out-of-order execution. RISC and CISC are two major processor architectures. ARM processors are based on RISC whereas Intel x86 processors mainly follow CISC architecture. Multi-core processors execute multiple threads simultaneously and cache memory reduces memory access time by storing frequently used data close to the CPU. Q4. Physics is the branch of science that studies matter, energy, motion and the interactions between them. Newton's laws of motion explain the relationship between force and acceleration while the law of gravitation describes the attraction between masses. Work, power and energy are fundamental concepts in mechanics. Kinetic energy depends on the motion of an object whereas potential energy depends on its position. Electricity includes concepts such as current, voltage, resistance and Ohm's law. Magnetism explains the behavior of magnetic fields and electromagnetic induction forms the basis of electric generators and transformers. Light exhibits both wave and particle properties and optics includes reflection, refraction, lenses and mirrors. Sound is a mechanical wave that requires a medium for propagation while electromagnetic waves can travel through vacuum. Q5. Chemistry is the scientific study of matter, its composition, properties and chemical reactions. Matter exists in the form of solids, liquids and gases. Atoms consist of protons, neutrons and electrons, and elements combine to form compounds through chemical bonding. The periodic table classifies elements based on atomic number and electronic configuration. Chemical reactions involve reactants converting into products while obeying the law of conservation of mass. Acids donate hydrogen ions whereas bases accept them, and the pH scale measures acidity and alkalinity. Organic chemistry focuses on carbon compounds including hydrocarbons, alcohols, aldehydes and carboxylic acids. Inorganic chemistry studies metals, salts and minerals. Concepts such as oxidation, reduction, catalysts, equilibrium, electrochemistry and polymers are important in industrial applications.
